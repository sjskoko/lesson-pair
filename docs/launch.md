# Release copy

## Short English introduction

LessonPair is an open agent skill for language learners: one lesson becomes two linked Notion pages, one for video preparation and one for writing, feedback, and review. It preserves the original writing, labels AI corrections, and includes a small offline formatter with checks for broken table markup. MIT licensed; examples are synthetic.

Try it: https://github.com/sjskoko/lesson-pair

## 한국어 소개

영어 수업 전 영상 예습과 수업 후 작문·피드백을 두 페이지로 연결하는 오픈소스 스킬 LessonPair를 공개합니다. 원본 작문을 보존하고, 선생님 메모와 AI 교정을 구분하며, 복습 문제와 재작문까지 이어집니다. 노션 표 오류를 확인하는 로컬 도구도 포함했습니다. MIT 라이선스이며 모든 공개 예시는 가상 자료입니다.

사용해 보기: https://github.com/sjskoko/lesson-pair

## Sharing checklist

- Share a useful example and a clear installation route.
- Use newly written fictional material, not personal study screenshots.
- Respect each community's self-promotion rules.
- Ask for specific feedback; do not buy stars, use bots, or mass-post.
- Improve the project based on real reports. Stars are not guaranteed.
