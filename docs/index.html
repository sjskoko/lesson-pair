04 / GOOD TO KNOW

Before your first video

Can I really start with one URL?

Yes, when captions are accessible to your host. Otherwise, paste a transcript or excerpt. The local tool can attempt YouTube captions using optional yt-dlp. It does not transcribe audio or infer missing content.

Is the ChatGPT plugin publicly listed?

The repository includes a skills-only plugin and marketplace manifest. Installation depends on host/workspace support. It is not yet in OpenAI's public plugin directory; the guide includes a portable fallback.

Is the method proven or token-free?

We have not run a controlled efficacy study. The workflow uses familiar practice and recall principles. The code is MIT licensed; AI execution still uses your host/provider's tokens, compute and limits.

What about my old Notion lessons?

The earlier version is preserved on legacy/english. Its formatter and paired-note workflow remain available. Existing private pages are not automatically migrated.
