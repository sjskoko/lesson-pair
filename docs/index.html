02 / ONE SESSION. TWO CONNECTED PAGES.

A home for both halves of learning.

Built for video-based lessons, conversation tutoring, and learners who want to revisit their own writing. Explanations can follow your language; source text stays in its original language.

BEFORE THE LESSON

Preparation page

  • Video link and available transcript
  • Section-by-section explanation and grammar
  • Three expressions to try in conversation
AFTER THE LESSON

Writing & review page

  • Original writing and teacher notes, unchanged
  • Corrections with reasons and attribution
  • Hidden-answer practice and a timed rewrite

Both pages belong to one Notion session. The workflow checks for an existing session before creating one, adds links in both directions, and guides you through lesson, review-pending, and calendar views. Review dates are planning fields; reminders require a separate setup.

03 / YOUR WORDS STAY YOURS

Organize the feedback.

LessonPair preserves learner writing and teacher notes verbatim. It labels AI additions, keeps unfinished sentences unresolved, and checks saved Notion tables for literal markup errors.

The repository contains only synthetic examples. The local Python formatter has no network calls, telemetry, or model dependency. AI-assisted editing and Notion saves use the services you connect.

04 / BEFORE YOU START

Common questions

Is this a Notion template or an AI skill?

It includes paired page templates, an Agent Skills package, and a local Python formatter. A compatible assistant uses the skill to organize material and write through a connected Notion integration. It is not a one-click Notion template marketplace listing.

Can I use it with ChatGPT or Codex?

Use a host that supports skill installation. Codex and ChatGPT Work setup options are in the installation guide. For a custom GPT without a skill loader, the guide includes a portable prompt and source links for manual adaptation.

Does it work without model tokens?

The local formatter runs on Python alone; it formats supplied JSON and does not generate corrections. Asking an AI to interpret or correct a lesson uses the host's model context and normal usage limits. Private Notion access requires authorization.

Does it watch the video or grade my speaking?

No automatic transcription or speech scoring is bundled. Supply an available transcript for source-based preparation. Missing meaning, teacher feedback, scores, and completed practice must not be invented.
