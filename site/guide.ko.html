ChatGPT Work 또는 호환 도구

해당 환경의 스킬 생성·설치 기능에 같은 폴더를 설치해달라고 요청하세요. 지원되는 환경에서는 @lesson-pair 또는 $lesson-pair로 호출합니다. 노션은 도구에서 제공하는 인증 절차로 연결하고, 정리할 학습 허브의 접근 권한을 부여합니다.

이 수업을 LessonPair로 내 노션 학습 허브에 정리해줘.
기존 영상 예습 페이지와 이번 작문·피드백을 연결해줘.
작문 원본은 그대로 보존하고, 짧은 재작문 문제도 추가해줘.

스킬 로더가 없는 커스텀 GPT

아래 프롬프트와 스킬 원문·연결된 참고 문서를 지침이나 지식 자료로 직접 적용할 수 있습니다. 자동 설치와는 다릅니다. 웹 탐색·지식 파일·Actions·노션 연결 지원은 제품마다 다릅니다.

내 영어 수업을 예습과 복습 페이지 두 개로 연결해줘.
LessonPair의 SKILL.md를 사용하고 필요한 참고 문서만 읽어줘.
작문 원본과 선생님 메모는 그대로 보존하고 AI 교정은 구분해줘.
없는 자막·뜻·점수·복습 완료 여부를 만들어내지 마.
기존 수업이 있으면 이어서 수정해줘.
노션에 쓸 수 없다면 초안을 주고 저장되지 않았다고 알려줘.

노션에 수업 두 페이지 연결하기

학습 허브 아래 수업 데이터베이스를 두고, 각 수업 안에 예습·복습 하위 페이지를 만듭니다. 수업 행에서 두 페이지를 바로 열 수 있게 하고, 각 페이지에도 상대 페이지 링크를 추가합니다.

수업 속성용도
이름·회차·수업 날짜같은 수업을 찾고 중복 생성을 방지합니다.
예습 페이지·복습 페이지데이터베이스에서 어느 쪽이든 바로 엽니다.
상태·다음 복습일복습 대기 보기와 달력을 구성합니다. 완료는 확인 후 표시합니다.
정리 날짜실제 수업일과 자료를 정리한 날을 구분합니다.

전체 수업·복습 대기·달력·재사용 양식 보기가 유용합니다. 양식용 행은 실제 수업 목록에서 제외하고, 기존 허브가 있다면 현재 구조를 존중합니다. 자세한 저장·검증 방법은 노션 작업 지침에서 확인할 수 있습니다.

  1. 영상과 제공된 자막으로 예습합니다.
  2. 수업 후 작문 원본과 선생님 메모를 모읍니다.
  3. 출처가 표시된 교정과 활용할 표현 세 가지를 정리합니다.
  4. 정답을 가린 문제를 풀고, 교정을 보지 않고 다시 씁니다.
  5. 복습 날짜를 정하고 직접 완료 여부를 확인합니다.

복습일 속성만으로 자동 알림이 생기지는 않습니다. 알림은 별도로 설정해야 합니다.

AI 없이 로컬 정리 도구 실행하기

Git과 Python 3.10 이상이 필요합니다. 추가 실행 패키지·API 키·모델 토큰은 필요하지 않습니다. 아래 입력 파일은 새로 만든 가상 자료입니다.

git clone https://github.com/sjskoko/lesson-pair.git
cd lesson-pair
python3 skills/lesson-pair/scripts/lesson_pair.py render examples/lesson.synthetic.json --out output/demo
python3 skills/lesson-pair/scripts/lesson_pair.py check output/demo/02-review.notion.md

output/demo/session.md를 열어 결과를 확인하세요. 예습·복습 초안과 입력 JSON을 그대로 보존한 파일이 생성됩니다. 도구는 제공된 자료를 문서로 만들며, 교정 생성·영상 시청·노션 저장은 하지 않습니다. 기존 결과를 덮어쓰지 않으므로 재실행할 때는 새 출력 폴더를 지정하세요.

직접 입력을 준비할 때는 JSON 필드 설명을 참고하세요. 실제 학습 자료와 생성 결과는 비공개로 보관합니다.

잘 안 될 때 확인할 것

노션에 <table> 태그가 그대로 보여요

.notion.md 파일은 Notion MCP의 확장 Markdown을 사용합니다. 일반 편집기에 붙여 넣으면 표 대신 태그가 표시될 수 있습니다. 연결 도구에서 지원하는 형식으로 저장하고, 저장한 페이지를 다시 읽어 행·셀 구조를 확인하세요. API 성공 응답만으로 화면의 표가 올바르다고 판단하지 않습니다.

자막을 못 찾거나 노션에 저장하지 못해요

자막을 제공하거나, 확인 가능한 내용만으로 예습하도록 요청하세요. 노션 연결이 없다면 초안과 미저장 상태를 분명히 받으세요. 공개 저장소가 개인 작업 공간 접근 권한까지 제공하지는 않습니다.

개인 학습 기록은 비공개로

공개 이슈·PR·데모·스크린샷에는 가상 예시만 사용하세요. 실제 작문·선생님과의 대화·개인 노션 ID·인증 정보는 공개 저장소 밖에 보관합니다. Git에서 제외된 private/·local/ 폴더는 실수 방지에 도움이 되지만 접근 제어 수단은 아닙니다.

Python 도구는 네트워크 통신이나 사용 기록 수집을 하지 않습니다. AI와 노션을 사용하면 권한을 부여한 자료가 해당 서비스에서 처리됩니다. LessonPair 자체 서버는 없습니다. MIT 라이선스는 AI 서비스의 요금이나 이용 한도를 없애지 않습니다.

AI가 읽을 공개 진입점

짧은 스킬 원문을 먼저 읽고, 작업에 필요한 참고 문서만 가져오도록 구성했습니다. 일반적인 공개 파일 열람에는 개인 GitHub 접근 토큰이 필요하지 않지만, 제공 서비스의 요청 한도는 적용될 수 있습니다.

  • Raw SKILL.md — 목적·작업 유형·원문 보존 규칙.
  • llms.txt — 문서와 원본 파일의 짧은 링크 색인.
  • llms-full.txt — 소개·설치법·스킬 참고 문서를 모은 텍스트.
  • project.json — 프로젝트 정보와 주요 진입점.

텍스트 색인은 직접 자료를 가져오기 쉽게 만든 안내입니다. 모든 GPT의 자동 설치, 모델 토큰 면제, 검색 등록 또는 AI 답변 인용을 보장하지 않습니다.
