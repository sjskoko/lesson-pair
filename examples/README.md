# A completely fictional lesson

The example about **urban trees** was written specifically for this repository. It is not a real learner's writing, a teacher conversation, or a transcript of a video. Its dates and session number are fictional.

| Original sample | Proposed correction | Why |
| --- | --- | --- |
| Trees gives shade. | Trees give shade. | Plural subject |
| I think city need more tree. | I think cities need more trees. | General plural reading; confirm intent |
| They also... | Leave unresolved | Do not guess the learner's meaning |

Run the quick-start command in the main README to see the paired files. The source JSON includes example Korean explanations, attribution labels, recall questions, and unchecked review tasks.

For contributions, replace identifying details with newly written fictional material rather than anonymizing a private screenshot.
