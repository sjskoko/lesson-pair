ChatGPT / Codex plugin

The repository includes a portable skills-only plugin and repository marketplace. In a supported Codex installation, add the source:

codex plugin marketplace add sjskoko/lesson-pair --ref main

Then install lesson-pair from that marketplace in a supported plugin interface. ChatGPT repository/workspace installation depends on client and admin controls. This plugin is not yet listed in OpenAI's public directory. Detailed plugin setup and status →

Another assistant or custom GPT

Attach SKILL.md, guided-session.md, and source-access.md. Ask the assistant to follow them. This is portable prompt use, not native plugin installation.

Your own model endpoint

The Python tutor supports a basic OpenAI-compatible Chat Completions endpoint. Configure your HTTPS provider or a local Ollama server using environment variables. No key belongs in this website or chat. Local tutor setup →

Say this to your assistant

Use LessonPair with this English video: [URL]. Guide me one small question at a time. Use available captions, or ask me for an excerpt. Let me try before showing a model answer. Explain in [my language].

Make a short first attempt, practice one or two gaps, and explain the idea again without looking at examples. The comparison uses your actual text. Later, use the expression in a different context.

Try the terminal tutor

Python 3.10+ and a separately running model endpoint are required. Start with the fabricated transcript:

git clone https://github.com/sjskoko/lesson-pair.git
cd lesson-pair
export LESSONPAIR_BASE_URL='http://localhost:11434/v1'
export LESSONPAIR_MODEL='YOUR-INSTALLED-MODEL'
python skills/lesson-pair/scripts/learn.py start --source examples/transcript.synthetic.txt
python skills/lesson-pair/scripts/learn.py run
python skills/lesson-pair/scripts/learn.py export

Use /hint or /example during practice and /quit to pause. Run again to resume. Optional yt-dlp allows a YouTube caption attempt using start --url URL. Missing captions require a file; no audio transcription is included.

Your records and your costs

Default sessions and exports stay in ignored private/. The CLI sends source and attempts to the endpoint you choose; the plugin uses your host AI. Provider policies and billing apply. Code is MIT licensed, but inference is not token-free. There is no telemetry or credential form in the static site.

Save Markdown or ask an authorized assistant to use Notion. The CLI does not write to Notion. Original text, AI feedback and assisted retries remain separate. All public samples are fabricated.
