예습 자료와 복습 기록을 한곳에.

영상을 보고 준비하는 영어 수업, 전화 영어, 회화 튜터링에 활용할 수 있습니다. 설명은 원하는 언어로 작성하고, 원문은 작성된 언어 그대로 남깁니다.

수업 전

① 영상 예습 자료

  • 영상 링크와 제공된 자막
  • 구간별 해석과 문법 메모
  • 대화에서 써볼 표현 세 가지
수업 후

② 수업·복습 기록

  • 작문 원본과 선생님 메모
  • 출처·이유가 표시된 문장별 교정
  • 정답을 가린 문제와 시간제한 재작문

두 페이지는 같은 노션 수업 아래에 놓입니다. 기존 수업이 있는지 확인하고, 서로 오갈 수 있는 링크를 연결합니다. 전체 수업·복습 대기·달력 보기를 구성하도록 안내합니다. 복습 날짜를 적는 것과 자동 알림을 설정하는 것은 별도입니다.

03 / 내가 쓴 말은 그대로

피드백을 정리해도
원문은 남습니다.

작문 원본과 선생님 메모는 그대로 보존합니다. AI의 보완은 따로 표시하며, 미완성 문장의 뜻을 추측해서 채우지 않습니다. 노션 표가 코드처럼 보이는 오류도 저장 후 확인하도록 안내합니다.

공개 저장소에는 가상 자료만 들어 있습니다. 로컬 Python 도구는 네트워크 통신·사용 기록 수집·모델 호출 없이 실행됩니다. AI 정리와 노션 저장은 사용자가 연결한 서비스를 통해 이루어집니다.

04 / 시작하기 전에

자주 묻는 질문

노션 템플릿인가요, AI 스킬인가요?

페이지 두 개의 양식, Agent Skills 형식의 스킬, 로컬 Python 정리 도구를 함께 제공합니다. 스킬을 지원하는 AI가 자료를 정리하고 연결된 노션에 저장합니다. 노션 마켓플레이스에서 한 번에 복제하는 상품은 아닙니다.

ChatGPT나 Codex에서 쓸 수 있나요?

스킬 설치를 지원하는 환경에서 사용할 수 있습니다. 설치 가이드에 Codex·ChatGPT Work 경로를 안내합니다. 스킬 로더가 없는 커스텀 GPT용으로는 직접 적용할 프롬프트와 원문 링크를 제공합니다.

정말 토큰 없이 사용할 수 있나요?

로컬 정리 도구는 Python만 사용합니다. 입력된 JSON을 문서로 만들며, 영어 교정을 생성하지 않습니다. AI에 해석·교정을 요청하면 모델 토큰과 서비스 이용 한도가 적용됩니다. 개인 노션에 저장하려면 연결 권한이 필요합니다.

영상을 자동으로 보고 말하기 점수도 매기나요?

자동 영상 받아쓰기나 말하기 채점 기능은 포함하지 않습니다. 영상에 근거한 예습을 위해서는 제공 가능한 자막이 필요합니다. 없는 뜻·피드백·점수·복습 완료 여부를 만들어내지 않도록 설계했습니다.
