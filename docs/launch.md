## Hooks to test, one at a time

| Audience | Hook | Destination |
| --- | --- | --- |
| Learners | 영어 교정, 저장만 하고 끝내고 있나요? | Clickable demo |
| Notion users | 영상 예습과 수업 오답을 두 페이지로 연결했습니다 | Korean README |
| Agent builders | An agent skill that preserves your mistakes, then helps you practice them | English README |

These are messaging hypotheses, not measured winners. Choose one hook for one relevant channel, keep its destination and image consistent, and record the publication time privately. Change one element for the next comparable post. Do not report an uplift without evidence.

## A small, efficient distribution plan

1. Start with the channel where the author already participates and where language study, Notion, or agent skills are on topic. Check its current self-promotion rules before posting.
2. Use one fictional sentence, one image, and one link. Send learners to the demo; send developers to the README. Avoid adding several competing calls to action.
3. Answer concrete questions and fix the first point that blocks installation or understanding. Share an update when there is a real improvement.
4. Review GitHub Traffic after 24 hours and again after seven days. Record aggregate visitors, referrers, stars gained, and useful feedback privately. A ratio of new stars to visitors is only a rough proxy; it does not prove which post caused a star. Cross-platform view counts are not comparable by default.

No external community posts or measured growth results are implied by this document. Do not publish account analytics, real lesson records, teacher identities, or private screenshots. Do not mass-post, buy stars, or invent users, endorsements, time savings, learning gains, or “zero-token AI” claims.
