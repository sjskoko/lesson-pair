# Paired lesson content

## Preparation page

Start with the lesson number/date, source video, preparation date, and paired review/session links. Use a brief goal callout and table of contents when the page is long.

For each available source segment, include:

1. English source text and source/timestamp if supplied.
2. Natural explanation or Korean translation when requested.
3. A few reusable expressions with meaning and a new example.
4. A grammar callout: source phrase → structure → conditions/exception → learner example.

Finish with three expressions to use in the lesson, possible discussion questions, and unchecked preparation tasks. Keep existing section grammar notes on update. Do not fabricate a transcript from a title or summary.

## Lesson/review page

Order the page for quick review:

1. Goal and three takeaways.
2. Separate closed toggles for learner original, teacher correction trace, and teacher notes, preserved verbatim.
3. Correction table: original / correction / reason / attribution. Mark unresolved meanings explicitly.
4. A readable corrected version; label substantive AI rewrites separately.
5. Grammar table: expression chunk / precise rule and exception / personal example.
6. Three whole-sentence chunks.
7. Three to six recall questions with answers in a closed toggle.
8. Blank timed-rewrite space with target and actual time separated.
9. Unchecked review criteria and questions for the next lesson.

Record scores only when requested or supplied; label evaluator and rubric. Do not score pronunciation without audio. Distinguish a target from measured time and teacher feedback from AI interpretation.

## Reusable blank set

Make a copy-ready session with two child templates and no real lesson dates, transcript, completion, grades, or private URLs. Keep the original under `구분=양식`. Include duplication instructions: duplicate parent and children, rename, set `구분=수업`, fill dates/video, update both URL properties and reciprocal mentions. Never claim automatic link remapping until verified.
