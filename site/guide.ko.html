ChatGPT / Codex 플러그인

저장소에 스킬형 플러그인과 마켓플레이스 패키지가 있습니다. 지원되는 Codex 환경에서 소스를 추가하세요:

codex plugin marketplace add sjskoko/lesson-pair --ref main

그다음 지원되는 플러그인 화면에서 lesson-pair를 설치합니다. ChatGPT의 저장소·워크스페이스 설치 경로는 클라이언트와 관리자 설정에 따라 다릅니다. OpenAI 공개 디렉터리에 등록된 상태는 아닙니다. 설치 방법과 배포 상태 →

이렇게 시작하세요

LessonPair로 이 영어 영상을 내 말로 설명하도록 도와줘: [링크]. 자막을 가져올 수 없으면 내게 발췌를 요청해. 한 번에 작은 질문 하나씩 하고, 내가 답하기 전에 모범 답안을 먼저 보여주지 마. 설명은 한국어로 해 줘.

먼저 짧게 답하고, 표현 한두 개를 연습하고, 예시를 보지 않고 다시 설명합니다. 실제로 작성한 두 답변을 비교한 뒤, 나중에는 다른 상황에서 같은 표현을 사용해 봅니다.

터미널로 시작하기

Python 3.10 이상과 별도로 실행한 모델 서버가 필요합니다. 가상 자막으로 실행해 보세요:

git clone https://github.com/sjskoko/lesson-pair.git
cd lesson-pair
export LESSONPAIR_BASE_URL='http://localhost:11434/v1'
export LESSONPAIR_MODEL='YOUR-INSTALLED-MODEL'
python skills/lesson-pair/scripts/learn.py start --source examples/transcript.synthetic.txt --language Korean
python skills/lesson-pair/scripts/learn.py run
python skills/lesson-pair/scripts/learn.py export

연습 중 /hint, /example을 사용하고 /quit로 멈출 수 있습니다. 다시 run을 실행하면 이어서 진행합니다. 선택적으로 yt-dlp를 설치해 start --url URL로 YouTube 자막을 시도할 수 있습니다. 자막이 없으면 파일이 필요하며, 음성 전사는 포함되지 않습니다.

내 기록과 이용 비용

기본 기록은 Git에서 제외된 private/에 저장됩니다. 로컬 도구는 선택한 엔드포인트에 원문과 답변을 보내고, 플러그인은 현재 호스트 AI를 사용합니다. 각 제공자의 정책·요금이 적용됩니다. 코드는 무료지만 AI 추론은 토큰 없이 실행되지 않습니다.

Markdown으로 저장하거나 연결된 AI에게 노션 저장을 요청할 수 있습니다. CLI 자체는 노션에 쓰지 않습니다. 원문·AI 피드백·도움받은 답변을 구분하며, 공개 예시는 모두 가상 자료입니다.

이전 방식도 계속 사용할 수 있습니다

노션 중심 버전은 legacy/english에 보존했습니다. main에서도 기존 포맷과 정리 도구가 동작합니다. 기존 노션 기록은 자동으로 이전하지 않습니다. 보존된 버전 확인 →
